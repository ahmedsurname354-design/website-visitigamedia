Untuk menambahkan foto Rental LED ke portofolio:

1. Buat folder baru:
   public/portfolio/rental
2. Letakkan foto Rental LED di folder itu dengan nama:
   - rental-1.jpg
3. Pastikan file bisa diakses melalui:
   /portfolio/rental/rental-1.jpg

Setelah menambahkan foto, jalankan ulang server Vite jika diperlukan:

npm run dev
